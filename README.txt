NOVAREACH DIGITAL WEBSITE — BEGINNER GUIDE

FILES
- index.html: the content and words on the website
- style.css: the colours, layout, and visual style
- script.js: small interactions, such as the mobile menu
- README.txt: these instructions

IMPORTANT BEFORE PUBLISHING
In index.html, find hello@yourdomain.com and replace it with your real business email address. The sample portfolio images/cards are design concepts, not completed client projects.

HOW TO UPLOAD THE FILES TO GITHUB
1. Open your GitHub repository.
2. Click Add file, then Upload files.
3. On your computer, open the folder containing index.html, style.css, and script.js.
4. Select those three files (you can also select README.txt) and drag them into the GitHub upload box, or click choose your files and select them.
5. Scroll down and click Commit changes.

IMPORTANT: upload the files themselves, not only the ZIP file. index.html must be directly on the main repository page, not hidden inside a subfolder.

HOW TO PUBLISH WITH GITHUB PAGES
1. In your repository, click Settings.
2. In the left sidebar, click Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Choose branch main and folder /(root).
5. Click Save and wait a few minutes.
6. Your website address will look like https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/

HOW TO EDIT LATER
1. Open the file in your repository, for example index.html.
2. Click the pencil/edit icon.
3. Make a change.
4. Click Commit changes to save it.
5. GitHub Pages updates the published site after a short wait.

For example, to change a heading, edit the words between the relevant HTML tags in index.html. To change colours, open style.css and look near the top for the colour variables.
